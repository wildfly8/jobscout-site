JobScout Privacy Policy

Last updated: October 27, 2026

JobScout is a private, single-user tool. The only Google account it is ever connected to is its owner's own, and it keeps that account's data on a server the owner controls.

1. What JobScout is

JobScout is a personal job-search assistant written and operated by Tim Xu (“the owner”). It runs on a server controlled by the owner. It is not offered to the public, has no sign-up, and has no accounts for anyone other than the owner.

2. Google user data JobScout accesses

JobScout asks for one Google permission, read-only access to Gmail:

https://www.googleapis.com/auth/gmail.readonly

This permission lets JobScout read messages. It does not allow JobScout to send, delete, label or change any email, or to change anything else in the Google account.

JobScout is set up to look at two kinds of messages:

  • Job-alert emails from LinkedIn and Indeed, found by configured sender and subject filters, looking back at most 14 days.
  • Replies from employers the owner has applied to, used to keep track of application outcomes.

Other messages are not processed.

3. How the data is used

  • Building a job shortlist. From each job-alert email JobScout records the job title, company, location, any salary text, the alert source and the time received.
  • Tracking application outcomes. From an employer reply JobScout suggests one outcome from a fixed list, such as an interview invitation or a rejection. The owner confirms or rejects every suggestion.

The data is used only to provide these features to the owner. It is not used for advertising, profiling, or any purpose for anyone else.

4. Storage and security

  • Data is stored on the owner's own server. Copies of processed job-alert emails are kept so that results can be reproduced.
  • Daily backups are made to storage controlled by the owner.
  • The Google access token and client credentials are kept in access-restricted files on that server and are never stored in source control. The code repository is private.

5. Sharing and third parties

JobScout does not sell, rent or share Google user data, and no one other than the owner reads it.

There is one disclosed transfer. To classify an employer reply, the text of that email may be sent to an AI model provider through its paid API (for example Google Gemini or Anthropic Claude). It is sent only to return a classification to the owner, and only to providers whose terms exclude training on inputs. Google user data is not used to develop, improve or train generalized artificial-intelligence or machine-learning models.

Beyond that, data is disclosed only where the law requires it.

6. Google API Services User Data Policy

JobScout's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Retention, access and deletion

  • Data stays on the owner's server until the owner deletes it.
  • Access can be withdrawn at any time at myaccount.google.com/permissions. Withdrawing it stops JobScout from reading the mailbox immediately.
  • To delete stored data, the owner deletes JobScout's database, its stored raw emails and its backups.

8. Changes and contact

If this policy changes, the date at the top will change. Questions can be sent to timxu2007@gmail.com.
